# 프로젝트 구조

이 프로젝트는 전략 로직(core), 실험/백테스트(research), 실전/모의투자(live), 외부연동(infra), 데이터(data), 설정(config), 노트북(notebooks)으로 구성되어 있습니다.

## 주요 폴더 설명
- config: 실험/운영/전략별 설정
- core: 전략 로직 및 신호/비중 계산
- research: 백테스트 및 전략 탐색
- live: 실전/모의투자 엔진 및 브로커
- infra: 데이터/외부 API/저장/로깅
- data: 실제 데이터 저장소
- notebooks: 분석/발표용 노트북
